# FIGGO ATLAS

**FIGGO ATLAS** is an enterprise‑grade automation and orchestration platform for building, running, and scaling **scrapers, bots, and workflows** across distributed hardware — with **AI‑assisted intelligence** at its core.

It is designed to be **battle‑tested, trustworthy, and extensible**, enabling individuals and teams to automate complex data operations reliably, at scale, and with full observability.

---

## 🚀 What Problem Does FIGGO ATLAS Solve?

Modern automation faces several hard problems:

- Fragile scrapers that break easily
- Bot detection and counter‑measures
- Poor observability and debugging
- One‑off scripts that can’t be reused
- Lack of trust, auditability, and intelligence

FIGGO ATLAS solves this by providing a **central orchestration brain**, distributed execution nodes, reusable workflows, and an **AI layer** that continuously improves decisions.

---

- **Automation should be reliable before it is clever**

---

## 🏗️ High‑Level Architecture

FIGGO ATLAS is composed of four major layers:

1. **Control Plane (Atlas Core)**
   Central orchestration, scheduling, configuration, and policy engine.

2. **Execution Plane (Distributed Nodes)**
   Remote machines running headed/headless browsers, scrapers, and bots.

3. **Workflow Engine**
   Declarative, reusable automation pipelines with retries, branching, and state.

4. **AI / MCP Layer**
   An MCP (Model Control Protocol) server that enables LLMs to reason, suggest, and optimize workflows.

---

## 🤖 AI & MCP Capabilities

The MCP server enables:

- Natural‑language workflow creation
- Intelligent retry and failure analysis
- Adaptive scraping strategies
- Bot‑defense awareness and mitigation
- Workflow optimization suggestions
- Explainability: _why_ a decision was made

AI is **assistive and auditable**, never opaque or uncontrollable.

- **Node.js** (orchestrator, workers)

### Infrastructure

- **Docker** (workers & services)
